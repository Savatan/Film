# Film

Веб-приложение для просмотра каталога фильмов и работы с данными, получаемыми из внешних источников.

## О проекте

Проект объединяет веб-интерфейс каталога, хранение структурированных данных о фильмах и инструменты для получения и обработки информации. Для поиска похожих названий используется RapidFuzz.

## Основные части

- Веб-интерфейс на Flask.
- Работа с данными через SQLAlchemy.
- Хранение данных в PostgreSQL при запуске через Docker Compose; приложение также поддерживает SQLite через конфигурацию `DATABASE_URL`.
- Получение и разбор веб-страниц с помощью Requests и BeautifulSoup.
- Сопоставление похожих названий с помощью RapidFuzz.

## Технологии

Python · Flask · SQLAlchemy · PostgreSQL · SQLite · Requests · BeautifulSoup · RapidFuzz · Docker Compose

## Запуск через Docker Compose

Требуется установленный Docker с поддержкой Docker Compose.

```bash
git clone https://github.com/Savatan/Film.git
cd Film
docker compose up --build
```

Сервис приложения настроен на порт `5000`. После запуска откройте http://localhost:5000.

Для остановки:

```bash
docker compose down
```

Данные PostgreSQL сохраняются в Docker volume, а каталог `data` приложения подключается как локальная папка.

## Структура

- `app/` — веб-приложение.
- `database/` — модели данных.
- `data/` — каталог для файловых данных приложения.

Перед публикацией и развёртыванием рекомендуется задать собственные параметры окружения и не использовать тестовые секреты в production.
