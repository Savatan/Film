# Film

Веб-приложение для работы с каталогом фильмов и сбора данных из внешних источников.

В проекте используются API, база данных и инструменты обработки данных. RapidFuzz помогает находить похожие названия, а Requests и BeautifulSoup — получать и разбирать информацию со страниц.

**Стек:** Python · FastAPI · SQLAlchemy · PostgreSQL · RapidFuzz · BeautifulSoup · Jinja2 · Docker
