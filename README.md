# Film

Проект для сбора и объединения информации о фильмах из нескольких каталогов.

## Основные задачи

- Получение данных из IMDb, TMDb и Кинопоиска.
- Обработка и сопоставление записей из разных источников.
- Поиск потенциальных дубликатов по названиям и другим данным.
- Хранение данных в базе и предоставление доступа через API.

## Технологии

- Python
- FastAPI / Flask
- PostgreSQL
- Docker
- RapidFuzz
