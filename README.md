# Film

Проект для работы с данными о фильмах и объединения информации из нескольких источников.

## Цель проекта

Собирать данные о фильмах из внешних каталогов, сопоставлять записи и уменьшать количество дублей, когда один и тот же фильм представлен в источниках по-разному.

## Планируемые направления

- Получение данных из каталогов фильмов, включая IMDb, TMDb и Кинопоиск.
- Нормализация названий и метаданных.
- Сопоставление похожих записей и поиск потенциальных дублей с помощью нечёткого сравнения строк.
- Хранение и предоставление данных через серверный API и базу данных.

## Технологии проекта

В проектной задумке рассматриваются Python, FastAPI или Flask, PostgreSQL и RapidFuzz. Состав фактически используемых библиотек и способы запуска следует сверять с текущим кодом репозитория.
